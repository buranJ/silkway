# Silk Way — этап 1: содержание и визуальное направление

Статус: **предложение на согласование, 29 сентября 2026**. Приложение Next.js не изменено. Это отдельный адаптивный макет, не готовый сайт. Новая 3D-модель и производственные анимации не реализованы.

## Просмотр

Из корня проекта: `node design/stage-1/preview.mjs`. Адрес: http://127.0.0.1:3002.

- `/` — композиция главной, адаптивная от 320 px.
- `/trade.html` — пилот внутренней страницы.
- `/motion.html` — раскадровка и поведение на телефоне.
- `/materials.html` — изображения и ограничения источников.
- `content-map.md` — сверка старого и текущего содержания, назначения и вопросы.

Предпросмотр привязан только к loopback; не публикует проект, не принимает заявки. Изображения читает из `public`, шрифт — из текущей сборки Next (при отсутствии сборки используется Arial). Оригиналы не изменяет.

## Решение

**Архитектура на первом плане, информация рядом.** Берём у Faropoint свободную композицию и согласованный рассказ; у Industrial City — предметность; у BIG — крупную архитектуру и ясные пояснения. Сохраняем Manrope, логотип Silk Way, красный #B71936 и тёмно-синий #193152. Белый фон становится основным; тёмные разделы выделяют территорию и контактный финал, а не всё подряд.

Верх главной: ясное название → краткое назначение → большой исходный рендер. Текст не перекрывает корпуса. Один основной призыв — выбрать направление. Нет декоративных номеров, искусственного шума, фоновых сеток, бесконечной бегущей строки и загрузочной заставки.

Главная: первый экран → выбор направления → кратко о проекте и история → территория → расположение/инфраструктура → контакт. Четыре направления не пересказываются в трёх последовательных анимационных секциях.

Внутренняя: название → крупный рендер → факты с областью применения → навигация по разделу → корпуса и условия → галерея → связь. На пилоте не выдаём EXPO-рендер за фотографию действующего торгового блока. Визуал подписан как проектный.

## Поведение и технологическая граница

Для этой стадии макеты статичны. Работают навигация между макетами, мобильное меню, раскрытие текста и выбор кадров раскадровки. Все кнопки контакта ведут к пояснению/существующему номеру; формы отправки нет.

В производстве: Next Server Components для текстов; отдельные клиентские островки для сцены и галереи; CSS Modules для локального оформления. Существующие GSAP/Three.js используем без установки ещё одного анимационного стека. Обновление Next или библиотек не является частью этого этапа.

Анимация первого экрана: короткое раскрытие изображения, лёгкое движение ракурса только при наличии подходящей сцены. Плоское изображение нельзя растянуть шейдером и назвать новой 3D-реконструкцией. Интерактивная территория — отдельная задача: выбор зоны → камера → факты → страница направления.

## Мобильный сценарий

- Композиция, а не уменьшенный настольный экран. Заголовок 38–44 px, текст от 16 px, поля 20 px.
- Изображение после названия и краткого описания; полезное действие доступно сразу.
- Нет горизонтального перехвата прокрутки и обязательного пролистывания 3D-ролика.
- Модель перед длинным объяснением; выбор зоны — крупные элементы управления, карточка под сценой.
- Цель для кнопок — не меньше 44 px; меню с Escape, возвратом фокуса и обычной клавиатурной навигацией.
- Reduced motion: без пролётов камеры и параллакса; сведения не пропадают.

## Что согласовываем

1. Светлый архитектурный первый экран с конкретным названием вместо большого лозунга поверх фасада.
2. Соотношение белого, фирменного синего и красного, размеры заголовков и спокойный ритм.
3. Новую структуру главной и подробную, но не монотонную внутреннюю страницу.
4. Отдельную интерактивную территорию вместо обязательного длинного 3D-вступления.

Согласование макета **не подтверждает** актуальность цен, стадий строительства, границ зон и компаний. Эти вопросы перечислены отдельно в `content-map.md`.
